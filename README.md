# Постобработка OCR паспорта РФ

По выводу OCR для каждого паспорта решаем: **принять** (и выдать 10 полей) или **отклонить**.
Принятый документ должен быть верен целиком, поэтому каждое поле подтверждается независимо:
визуальная зона сверяется с MRZ, место рождения и орган выдачи — со справочником и контекстом.

**Test: принято 1111 из 2000, прогноз — около 7 принятых с ошибкой.** Подробности — в [отчёте](REPORT.md).

## Запуск

Положите рядом с `postprocess.py` папки `data/` и `reference/` из пакета задания и выполните:

```
python postprocess.py data/test_predictions.jsonl answers.jsonl
```

Python 3.8+, только стандартная библиотека, CPU, без сети; около минуты на 2000 документов.
